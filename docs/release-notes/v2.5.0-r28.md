# v2.5.0-r28 — Wi-Fi from the settings menu; tracks with accented names load

<!-- debs: rebuild -->

New Mixxx build **and** a skin/Pi-script update. Two changes.

- **WI-FI in the settings menu** (`wifi-settings.patch`, patch 20). The cog's
  panel gains a **WI-FI** button above POWER OFF. It opens a full-screen page:
  the connection you are on with its IP address at the top, then the networks
  in range — strongest first, one row per network, tagged CONNECTED / SAVED /
  OPEN / ENTERPRISE with signal bars — with RESCAN and PREV / NEXT paging
  underneath. Tap a network to join it: open and saved networks connect
  straight away; a new secured one shows a password page with the on-screen
  keyboard, CONNECT on the keyboard joins. Tap the network you are connected
  to and it turns red, "TAP AGAIN TO FORGET"; a second tap within 5 s forgets
  it. BACK leaves the password page first, then the Wi-Fi page. The cog and
  tapping outside the menu close everything, and the menu always reopens on
  its main screen.

  The **on-screen keyboard** (shared with the Search page) grew a **SHIFT**
  key (one-shot: it drops after the next key, like a phone) and a **?123**
  layer with the punctuation a Wi-Fi password may need. Letter keys now show
  lower case until SHIFT is on. The Search keyboard is one row taller for it.

  It talks to NetworkManager through `nmcli`, never blocking the interface
  (a scan takes a few seconds; "SCANNING…" shows meanwhile). A wrong password
  is reported on the password page with the text kept so you can fix it, and
  the half-made profile is removed so it cannot show up as SAVED later. A
  saved network whose stored password no longer works drops you straight
  into the password page.

- **Tracks with accented filenames load again** (`rekordbox-unicode-paths.patch`,
  patch 19, plus `pi/usb-mount.sh`). The reported file — *BASTI - La Mamá
  (Speedy Opera Edit)* — is a perfectly ordinary CBR 320 MP3; what failed was
  *finding* it. The Pi mounted FAT sticks without `utf8`, so the kernel
  presented the `á` in its default charset while rekordbox had written the
  UTF-8 name into `export.pdb`; the two never matched, Mixxx logged "File not
  found" and LOAD silently did nothing. FAT sticks are now mounted with
  `utf8=1`. Mixxx additionally retries a non-ASCII path that is not found as
  written in the other Unicode normalisation form (Mac-exported sticks can
  differ from the database on that), and a row whose file really is missing
  now shows a **TRACK FILE NOT FOUND ON USB** banner instead of doing nothing.

  `update-pioneered.sh` now installs the `pi/` mount layer on every update,
  so this and future mount-script fixes reach the unit without a manual copy.

## Install (on the Pi)

```
sudo ./update-pioneered.sh
```

Use the copy of `update-pioneered.sh` from this release (it is what installs
the mount script). The reboot at the end remounts the sticks with the new
options; if you skip it, unplug and re-insert them.

## Field checks

### Accented filenames

1. With the stick that carries *La Mamá* inserted after the reboot, run
   `mount | grep USBA` — the vfat line should include `utf8`.
2. `ls /media/USBA/Contents/…` (or wherever rekordbox put it): the filename
   shows **La Mamá**, not `La Mam?` or `La MamÃ¡`.
3. In Mixxx, browse to the track and tap LOAD 1: it **loads** and the screen
   returns to Overview as usual.
4. Pick any track and, with the stick still in, rename or delete its file
   from another machine (or pick a rekordbox entry whose file is gone): LOAD
   shows **TRACK FILE NOT FOUND ON USB** for ~3 s and nothing else happens.

### Wi-Fi

5. Cog → **WI-FI**. Within a few seconds the status line reads
   `CONNECTED TO <your network> · <ip>` (or NOT CONNECTED) and the list fills,
   your current network first and green.
6. **RESCAN** re-lists. If there are more than 6 networks, **NEXT ▶** pages and
   the hint reads PAGE 2/n.
7. Tap a **secured network you have never joined**: the password page
   appears with the keyboard. Type a deliberately wrong password (use SHIFT
   and ?123 at least once — the typed text shows in the box, capitals and
   symbols included), CONNECT: after up to ~30 s the hint says COULDN'T
   CONNECT — CHECK THE PASSWORD and the text is still there. Clear it, type
   the right one, CONNECT: the list comes back with that network green and
   the status line shows its IP.
8. Tap the connected network: it turns red, "TAP AGAIN TO FORGET". Wait 5 s
   — it reverts. Tap it twice: it is forgotten, the status goes NOT
   CONNECTED (NetworkManager may then auto-join another saved network).
   Tap it again: it asks for the password (it is no longer SAVED).
9. Open the password page and tap **BACK**: you are back at the list, not
   the menu. BACK again: the settings menu. Cog while on the Wi-Fi page:
   everything closes; open the cog again: the **main menu**, not Wi-Fi.
10. **Search page**: the keyboard still searches; SHIFT and ?123 change the
    key faces; a search typed with SHIFT on still finds the track (search is
    case-insensitive). Done still hides the keyboard.
11. Playback: a set running underneath is untouched throughout, including
    during a scan and a connect.

If connecting or forgetting fails immediately with "not authorized" in the
Mixxx log (`journalctl --user -u mixxx` or wherever it logs), add the sudoers
rule from README §5 and try again — Mixxx retries through `sudo -n nmcli` on
that error. If the page says NETWORKMANAGER (nmcli) NOT FOUND, the unit is not
running NetworkManager (it is the default on Raspberry Pi OS Bookworm and
later); `sudo apt install network-manager` and switch to it.
