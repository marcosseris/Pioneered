# v2.5.0-r30 — every keyboard key the same size; the update page says what to fix

<!-- debs: rebuild -->

New Mixxx build and a skin update. One visible fix to the on-screen keyboard,
and the SOFTWARE UPDATE page now names the fix when it cannot start.

- **The on-screen keyboard is laid out properly.** Two things were wrong at
  once, on the Search page and on Wi-Fi password entry.

  The letter rows were **a third the height** of the digit row and the
  bottom row. The keyboard is five rows tall, but the three letter rows sit
  inside one group that swaps for the punctuation rows when you tap `?123`,
  and that group was counted as *one* row's worth of height — so the three
  rows inside it shared it.

  Keys were also **as wide as their row allowed**: each row divided the
  screen by its own number of keys, so `z x c v b n m` (7 keys) had keys
  around 40% wider than `q…p` (10 keys), the `a…l` row was in between, and
  every key changed width again when you tapped `?123` for the 11-key
  punctuation rows.

  Now a key is one size everywhere. Rows have a fixed height, and a key is
  capped at 88px wide with short rows centred — so `a…l` sits half a key in
  from `q…p`, and the punctuation layer keeps the same key size as the
  letters. The space bar is deliberately the one key left wide, and SHIFT,
  `?123`, ⌫, clear and Done/CONNECT are one and a half keys each.

- **SOFTWARE UPDATE tells you what to do when it refuses.** The page runs
  the updater through `sudo -n`, and sudo's two refusals — the updater not
  being installed at `/usr/local/bin/update-pioneered.sh`, and the sudoers
  rule from README §6 being missing — both look like any other failed
  update: one line, exit 1. So the page said **UPDATE FAILED (exit 1)** and
  left you to work it out.

  It now recognises both and prints the command that fixes each, under
  **UPDATER NOT INSTALLED** or **UPDATE NOT PERMITTED**. Nothing about what
  it does has changed; only what it says when it never got started.

## If SOFTWARE UPDATE says "command not found"

That is the first of the two above, and it is expected once on any unit that
came from r28 or earlier. The updater installs itself to
`/usr/local/bin/update-pioneered.sh`, which is the fixed path the button
calls — but that step lives *inside* the r29 script, so updating to r29 with
an older copy of the script never put it there.

Run the script once from a shell on the Pi and it fixes itself:

```
curl -fL -o update-pioneered.sh \
  https://raw.githubusercontent.com/ogg755/Pioneered/v2.5.0-r30/pi/update-pioneered.sh
chmod +x update-pioneered.sh
sudo ./update-pioneered.sh
```

After that the button works on its own, provided the sudoers rule from
README §6 is in place.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

### Keyboard

1. Search → the keyboard icon. All five rows are **the same height**, and
   the digit row is no taller than `q w e r t y`.
2. Every letter and digit key is **the same width**. `a s d f g h j k l` is
   centred, indented half a key from the row above; `z x c v b n m` is
   centred too, and its keys are no wider than any other.
3. Tap `?123`. The punctuation keys are the **same size** as the letters
   were, and the keyboard does not change height or jump.
4. Tap ⇧. Faces change to capitals with **nothing moving**.
5. The space bar is the wide key on the bottom row; ⇧, `?123`, ⌫, clear and
   Done are all the same size as each other.
6. Type a few letters: they still reach the search box, and Done still hides
   the keyboard.
7. Cog → WI-FI → a network → the password keyboard: same layout, slightly
   taller rows, CONNECT in place of Done.

### Update page

8. Cog → **SOFTWARE UPDATE** → UPDATE twice. It runs as before and ends with
   **UPDATE INSTALLED — TAP RESTART TO FINISH**.
9. To see the new message, rename the updater away
   (`sudo mv /usr/local/bin/update-pioneered.sh /root/`) and tap UPDATE
   twice: the status reads **UPDATER NOT INSTALLED — SEE THE LOG** and the
   log carries the `curl`/`sudo bash` lines that fix it. Put it back
   afterwards (`sudo mv /root/update-pioneered.sh /usr/local/bin/`).
10. With the sudoers rule removed, the same tap ends with **UPDATE NOT
    PERMITTED — SEE THE LOG** and the `echo … | sudo tee` line. Nothing is
    installed in either case.
