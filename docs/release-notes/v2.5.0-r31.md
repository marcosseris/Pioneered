# v2.5.0-r31 — the BROWSE knob zooms the waveforms; BPM in the track list

<!-- debs: rebuild -->

New Mixxx build. Two additions: the BROWSE rotary now zooms the waveforms
when the waveforms are what you are looking at, and the browse list gained a
BPM column.

- **BROWSE zooms the waveforms on the Overview tab.** There was no hardware
  way to zoom at all before this — the knob only ever scrolled the list, even
  while sitting on the Overview tab with no list in sight.

  The knob now follows the screen. On **Overview**, one detent is one zoom
  step. On **Browse** or **Search**, it scrolls the track list exactly as it
  always did, so nothing is taken away: the encoder is still the only way to
  move through a list without touching the screen.

  Turning **clockwise zooms in**. Both decks zoom together to the same level —
  the two waveforms are stacked one above the other and can only be read
  against each other at a matching scale. There are 10 steps; the knob stops
  at each end.

  Pressing BROWSE, and SHIFT + BROWSE, are unchanged.

- **BPM column in the browse list.** The columns are now **#, Title, Artist,
  BPM, Key, Duration** — BPM sits next to Key, the two numbers you actually
  read when picking the next track. The value is the one rekordbox analysed
  and wrote to the USB stick; it was already being imported and was simply
  never shown.

  Tapping the **BPM** header sorts by it. Opening a playlist still comes up
  sorted by **#**, as before.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

### BROWSE knob — zoom

1. On the **Overview** tab with a track loaded, turn BROWSE **clockwise**:
   both waveforms zoom **in** (less track on screen, beats further apart).
   Counter-clockwise zooms back out.
2. Both decks stay at the **same** zoom, whether or not the second deck has a
   track loaded.
3. Keep turning clockwise: it stops at the closest zoom and stays there —
   no wrap-around, no jump back to the far end. Same at the other end.
4. Tap **Browse**. Turn BROWSE: the list scrolls, one row per detent, at the
   same speed as before this update. It does **not** zoom.
5. Tap **Search**. Same again — the knob scrolls the results.
6. Back to **Overview**: the knob zooms again, starting from the zoom level
   you left it at.
7. Load a track from the browser. The screen returns to Overview (as in r26)
   and the knob zooms straight away, with no extra tap needed.
8. Press BROWSE (no turn): focus still moves between the list and the tree.
   SHIFT + press still moves it back.

### BPM column

9. Insert a USB stick, tap USB A, open a playlist. The columns read
   **# · Title · Artist · BPM · Key · Duration**, left to right.
10. BPM shows a number with one decimal (e.g. `128.0`). A track rekordbox
    never analysed shows `-`.
11. **This is the one to check on a unit that has run an earlier version:**
    the BPM column must be *there*. It is a new column in a list whose layout
    the unit has remembered since r30, and the old layout had it hidden.
12. No checkbox, tick or padlock appears in the BPM cells — just the number,
    right-aligned, in the same style as Duration.
13. Tap the **BPM** header: the list sorts by BPM, and again for descending.
    Leave the playlist and come back: it opens on **#** order again.
14. The other columns are unchanged — Title and Artist still fill the width,
    Duration still sits hard against the right edge, and the green Key
    highlight still works against the playing deck.

## Note

This build has not been run on hardware. It is a clean build of the full
patch series; everything above is a check to perform, not a check that has
been performed.
