# v2.5.0-r32 — the BROWSE zoom actually works; no more on-screen LOAD buttons

<!-- debs: rebuild -->

New Mixxx build **and** a skin change — install both.

- **The BROWSE knob really does zoom now.** r31 advertised this and it did
  nothing on the unit. The reason is worth knowing, because it applies to
  anything Pioneered ever tries to do through a controller mapping: r31 put
  the zoom in the DDJ-400 mapping and its script, in
  `/usr/share/mixxx/controllers`. Mixxx prefers a mapping of the same name
  from **your own** `~/.mixxx/controllers`, and it quietly writes a copy there
  whenever a mapping gets marked dirty — so on a unit that has one, the deb's
  patched mapping and script are never loaded at all. No package can fix that,
  because no package owns that directory.

  r32 does the zoom inside Mixxx itself, at the far end of the stock binding.
  The mapping is left exactly as it ships, so there is nothing left to shadow.

  Behaviour is what r31 described: on **Overview**, one detent is one zoom
  step and **clockwise zooms in**; both decks always sit at the same zoom;
  there are 10 steps and it stops at each end. On **Browse** or **Search** the
  knob scrolls the track list exactly as it always has. Pressing BROWSE, and
  SHIFT + BROWSE, are unchanged.

- **The on-screen LOAD 1 / LOAD 2 buttons are gone.** They duplicated the two
  physical LOAD buttons your hand is already on, and cost 220 px of a 480 px
  screen to do it. The deck overviews at the bottom of **Browse** and
  **Search** now run the full width instead — at this size the overview is the
  only place you can see a cue point or how much of the track is left while
  you are picking the next one.

  Loading is unchanged in every other way: the physical LOAD buttons still
  load, still return you to Overview, and still show **PAUSE DECK TO LOAD**
  when the deck is playing.

  One thing does go with them: **hold-LOAD-for-7 s to restart Mixxx**, which
  lived on those on-screen buttons. Cog → **RESTART MIXXX** does the same job
  and is still there.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

The updater installs the skin as well as the debs, which matters this time —
the LOAD buttons are a skin change and the zoom is a deb change, and the two
are independent. If you install the debs by hand, copy the skin too.

## Field checks

### BROWSE knob — zoom

1. On the **Overview** tab with a track loaded, turn BROWSE **clockwise**:
   both waveforms zoom **in** (less track on screen, beats further apart).
   Counter-clockwise zooms back out. **This is the check that failed in r31.**
2. Both decks stay at the **same** zoom, whether or not the second deck has a
   track loaded.
3. Keep turning clockwise: it stops at the closest zoom and stays there — no
   wrap-around, no jump back to the far end. Same at the other end.
4. Tap **Browse**. Turn BROWSE: the list scrolls, one row per detent, at the
   same speed as before. It does **not** zoom.
5. Tap **Search**. Same again — the knob scrolls the results.
6. Back to **Overview**: the knob zooms again, from the level you left it at.
7. Load a track from the browser. The screen returns to Overview (as in r26)
   and the knob zooms straight away, with no extra tap needed.
8. Press BROWSE (no turn): focus still moves between the list and the tree.
   SHIFT + press still moves it back.

### LOAD buttons

9. Tap **Browse**. There are no LOAD buttons on screen; the two deck
   overviews fill the bottom strip edge to edge with a small gap between them.
10. Select a track and press the **physical LOAD 1**. It loads to deck 1 and
    the screen returns to **Overview**.
11. With deck 2 playing, select a track and press **physical LOAD 2**: the
    **PAUSE DECK TO LOAD** banner appears and you stay in the browser with
    your place in the list.
12. Tap **Search** and check the same strip there — no LOAD buttons, two
    full-width overviews.
13. Cog → **RESTART MIXXX** → tap again to confirm: Mixxx restarts. (This is
    now the only way to restart from the touchscreen.)

## Note

This build has not been run on hardware. The zoom path was traced through the
Mixxx sources and the patch series was verified to apply and round-trip
cleanly, but everything above is a check to perform, not a check that has been
performed.
