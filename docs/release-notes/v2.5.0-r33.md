# v2.5.0-r33 — jog nudge sensitivity is now a setting you can save

<!-- debs: rebuild -->

New Mixxx build **and** a skin change — install both.

- **Cog → JOG SENSITIVITY.** How far one nudge of the jog side ring bends the
  pitch is no longer baked into the build. The new page has one number, from
  **20% to 200%** of the feel r25 shipped, stepped 10 points at a time with
  **−** and **+**.

  Every step takes effect on the decks **immediately**, before you save
  anything. That is the point: a feel setting is only ever judged with a hand
  on the wheel, so you turn it down, nudge a running track, turn it down
  again, and stop when the beatmatch lands where your hand expects.

- **SAVE is what survives the reboot**, and it writes the file there and then.
  Mixxx normally saves `mixxx.cfg` on a clean exit — which is exactly what
  **POWER OFF**, two rows up in the same menu, never gives it. So SAVE flushes
  the file immediately instead. Pull the plug a second later and the setting
  is still there.

  The button tells you where you stand: it reads **SAVE** while the number on
  screen differs from the one on disk, and an inert grey **SAVED** once they
  match. Leaving the page without saving keeps the new feel for the rest of
  the session and offers SAVE again when you come back.

- **It is one setting for both decks**, and it lives inside Mixxx rather than
  in the DDJ-400 mapping. That matters for the same reason r32 did: a mapping
  in your own `~/.mixxx/controllers` shadows the one the deb installs, so
  anything that lives in the mapping can be silently overridden on a unit that
  has one. This cannot be.

- **Cueing is untouched.** Only the nudge on a *playing* deck is scaled.
  Turning a paused deck's wheel to find a cue point scrubs at exactly the
  speed it always has, whatever you set here.

The settings menu now has six rows instead of five, so the rows are slightly
shorter. Everything else about it is unchanged.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

The updater installs the skin as well as the debs, and this release needs
both: the page is a skin change, the setting behind it is a deb change.

## Field checks

1. Cog → the menu now lists **JOG SENSITIVITY** between SOFTWARE UPDATE and
   POWER OFF. All six rows fit the panel and none are clipped.
2. Tap it. The page shows **100 %** on a fresh unit, with **SAVED** (grey,
   inert) below it — nothing to write yet.
3. Tap **+** a few times: the number goes up in 10s and the SAVED button turns
   into an accented **SAVE**.
4. With a track playing, nudge the jog side ring. At **200 %** the pitch bend
   is roughly twice the push it was at 100 %; at **20 %** it is a fifth of it.
   The change is audible without leaving the page.
5. Keep tapping **+**: the number stops at **200 %**. Keep tapping **−**: it
   stops at **20 %**. Neither wraps.
6. Tap **SAVE**. The button becomes the grey **SAVED** immediately.
7. Tap **BACK**. You land back on the settings menu, not on the deck.
8. Reopen **JOG SENSITIVITY**: the saved number is there, showing **SAVED**.
9. **The reboot check.** Cog → **RESTART MIXXX** → tap again. When Mixxx comes
   back, nudge the wheel: the feel is the one you saved. Reopen the page and
   confirm the number and the grey SAVED.
10. **The power-cut check.** Change the value, tap SAVE, then Cog → **POWER
    OFF** → tap again. Power the unit back on: the saved value is still there.
11. Change the value but **do not** save, then BACK, then reopen the page: the
    unsaved number is still shown, with a live **SAVE**. Restart Mixxx without
    saving: it is back to the saved value.
12. Pause a deck and turn its jog side ring to scrub for a cue point — at
    **20 %** and at **200 %** it scrubs at the same speed as it always did.
13. Tap outside the page (the dark area around it): the whole menu closes, as
    it does from the main menu. Reopening the cog puts you back on the menu,
    not on the jog page.

## Note

This build has not been run on hardware. The patch series was verified to
apply and round-trip cleanly against Debian trixie's Mixxx 2.5.0 source, and
the skin XML parses, but everything above is a check to perform, not a check
that has been performed.
