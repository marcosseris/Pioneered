# v2.5.0-r36 — sticks open themselves, and loops stop turning up uninvited

<!-- debs: rebuild -->

New Mixxx build. No skin files changed, but install the update as usual.

- **Plug in a stick and it opens.** No button press. A rekordbox stick opens
  about a second after it mounts, straight to its playlists. A stick already
  in when the Pi boots opens as soon as the screen is up. USB A / USB B still
  switch between sticks. If both sticks are in at boot, USB A opens and USB B
  waits for its button.

- **One press used to take three.** Mixxx attached a stick's playlists in the
  background without telling the sidebar. So the first press opened the stick
  onto an empty list, the second closed it again, and the third found the
  playlists. The sidebar now refreshes by itself when the playlists land.

- **No more Mixxx folders.** That second press is what showed the whole
  stock Mixxx tree: Tracks, Auto DJ, Playlists, Crates, Computer, History
  and the rest. The sidebar now only ever shows your sticks. With no stick
  open it lists the sticks that are in, and it is empty when there are none.
  A press on the stick that is already open takes you back to its top
  instead of closing it, like a CDJ's source button. The Rekordbox help page
  that sometimes flashed up in the track list is gone too.

- **A pulled stick leaves the list.** If you pull a stick without holding
  its button to eject it, it now drops out of the sidebar within a second
  instead of lingering. (Still eject properly when you can.)

- **A track loads with no loop.** Loading a track armed an old loop without
  telling you: the last loop that deck had when the track was ejected, or
  the stick's first memory loop. It sat there, set but not running, until
  RELOOP/EXIT or LOOP IN turned it into a loop halfway through the track.
  Tracks now load with no loop. Saved loops stay on their hot cue pads.

- **With no loop running, LOOP IN starts a fresh loop.** After leaving a loop
  with RELOOP/EXIT, LOOP IN used to reuse the old loop's out point. Now it
  only sets the in point, and LOOP OUT decides where the loop ends, as on a
  Pioneer player.

- **Waveforms zoom out further.** The mouse wheel and the BROWSE knob on the
  Overview tab can zoom out half as far again as before (max zoom 10 → 15).

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

1. With Mixxx running, **plug in a rekordbox stick**: its playlists appear in
   the sidebar within a couple of seconds, without pressing anything.
2. **Reboot with a stick in**: it opens by itself once the screen is up.
3. **Press USB A on the open stick**: the list goes back to the stick's top.
   You never see Tracks / Auto DJ / Crates / Computer.
4. **Plug in the second stick**: the sidebar switches to it. USB A switches
   back.
5. **Hold USB A to eject**: the sidebar shows just the remaining stick (or
   nothing), not the Mixxx folders.
6. **Pull a stick without ejecting**: it disappears from the sidebar within
   a second or two.
7. Load a track that has memory loops, or one that had a loop on it when it
   was last ejected: **no loop is set** on load, and hot cue pads still hold
   the saved loops.
8. Make a loop, exit it with RELOOP/EXIT, then **LOOP IN, LOOP OUT** further
   on: the new loop runs between the two new points, not back to the old
   out point.
9. On the Overview tab, **turn the BROWSE knob anticlockwise**: the waveforms
   zoom out further than before.

## Note

This build has not been run on hardware, and the USB change has not been
compiled locally. The full patch series (28 patches) applies cleanly from a
fresh 2.5.0 source tree in both CI workflows, and the release build is the
first compile. If the build fails, the release will not publish and the Pi
stays on r35.

Checks 1 and 3 are the ones this release is about.
