# v2.5.0-r37 — hot cue pads that play, and backspins that spin

<!-- debs: rebuild -->

New Mixxx build. No skin files changed, but install the update as usual.

- **A hot cue pad starts the track.** On a paused deck, a pad used to play
  only while you held it, then jump back to the cue and stop when you let
  go, so a tap did nothing you could hear. Now a pad jumps to its cue and
  plays, and the deck keeps playing when you let go, like on a CDJ. A saved
  loop pad jumps to the start of the loop and plays it. Pads on a playing
  deck, setting a cue on an empty pad, and SHIFT + pad to delete work as
  before.

- **Backspins sound right.** Letting go of a platter that was still spinning
  ended the scratch at once, and the rest of the spin was read as pitch-bend
  nudges. So instead of the track spinning backwards and slowing down, it
  jumped back to forward play and got dragged backwards in bumps. That came
  from the r25 fix that stops the side of the wheel from scratching. Now the
  track follows the wheel until it has spun down (or, on a forward throw,
  slowed to playback speed), then eases back into play. Touching the platter
  again catches the spin. Nudging the side of the wheel is still a pitch bend
  and still never scratches.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

1. Set a hot cue, pause the deck somewhere else, and **tap the pad**: the
   deck jumps to the cue and keeps playing after you let go.
2. With a saved loop on a pad, pause the deck and **tap the pad**: the loop
   starts playing and keeps looping.
3. On a playing deck, **tap a hot cue pad**: it jumps and keeps playing, as
   before.
4. On a playing deck, **spin the platter top backwards hard and let go**: the
   track spins backwards with the wheel, slows as the wheel slows, then
   carries on playing forwards.
5. **Throw the platter forwards and let go**: the track speeds up with the
   wheel and settles back to normal speed as the wheel slows.
6. **Hold the platter still, then lift your hand**: the deck picks up
   straight away, with no delay.
7. Right after a backspin, **nudge the side of the wheel**: it bends the
   pitch and does not scratch.

## Note

This build has not been run on hardware, and has not been compiled
locally. The full patch series (30 patches) applies cleanly from a fresh
2.5.0 source tree. The release build is the first compile, and it runs
Mixxx's test suite, including the two new hot cue tests. If the build
fails, the release will not publish and the Pi stays on r36.

The backspin change is in the DDJ-400 controller script. If the Pi has an
old user copy of the mapping in `~/.mixxx/controllers/`, that copy wins and
the change will not take effect (the same goes for the r25 jog fix).
Deleting that file and restarting Mixxx fixes it.

Checks 1 and 4 are the ones this release is about.
