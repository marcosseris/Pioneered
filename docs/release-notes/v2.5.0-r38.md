# v2.5.0-r38 — Color FX, one Beat FX, played tracks and first-cue loading

<!-- debs: rebuild -->

New Mixxx build and new skin files. Install the update as usual.

- **Color FX buttons.** Under the Beat FX there are now four buttons:
  **SPACE**, **DUB ECHO**, **NOISE** and **FILTER**. They pick what both
  FILTER knobs do, like the SOUND COLOR FX buttons on a Pioneer mixer. With
  the knob at the centre you hear nothing. Turn it left for a low-pass sweep
  or right for a high-pass sweep, with the effect getting stronger towards
  either end. DUB ECHO's repeats keep ringing after you bring the knob back
  to the centre. FILTER is the plain filter the knob was before. The
  selected button is lit blue, and your choice is kept after a reboot.

- **One Beat FX that works straight away.** The two extra effect slots under
  the Beat FX are gone. The DDJ-400's **ON/OFF** button now works from the
  first press. Before, it did nothing until you had pressed BEAT ◀ or ▶.
  **BEAT ◀ / ▶** now step through the effects, and **LEVEL/DEPTH** takes
  effect wherever the knob is. You no longer have to turn it to zero first.

- **Played tracks are greyed out.** Once a track has played on a deck for
  30 seconds, it shows dimmed in the track lists. It stays that way until
  you eject or pull the USB stick it is on (or restart).

- **Tracks load at their first cue.** A track with memory cues or hot cues
  now loads at the earliest one instead of at 0:00. A track with no cues
  loads as before. After Mixxx has analysed a track like that, it moves to
  the track's first sound.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

1. After the update, **press ON/OFF on the DDJ-400** without touching
   anything else: the Beat FX turns on and its button lights.
2. **Turn LEVEL/DEPTH** from wherever it sits: the effect level follows it
   at once.
3. **Press BEAT ◀ / ▶**: the effect name on screen changes.
4. **Tap each Color FX button** and sweep a FILTER knob from centre to both
   ends. It is silent at the centre each time, and the lit button follows
   your taps. Tapping the lit button does nothing.
5. **Pick DUB ECHO, restart Mixxx** (Cog → RESTART MIXXX): DUB ECHO is still
   lit and still what the knob does.
6. **Load a track that has rekordbox memory cues**: it sits at the first
   cue, not at 0:00.
7. **Play a track for more than 30 seconds**, then open Browse: its row is
   grey. **Eject that stick** (hold USB), put it back: the row is normal
   again.

## Note

This build has not been run on hardware and has not been compiled locally.
The full patch series (34 patches) applies cleanly from a fresh 2.5.0 source
tree. The release build is the first compile, and it runs Mixxx's test
suite, including the two new load-at-first-cue tests. If the build fails,
the release will not publish and the Pi stays on r37.

Part of the Beat FX fix is in the DDJ-400 controller script. The ON/OFF fix
also works without it. BEAT ◀ / ▶ picking the effect and LEVEL/DEPTH working
straight away do not. If the Pi has an old user copy of the mapping in
`~/.mixxx/controllers/`, that copy wins. Deleting that file and restarting
Mixxx fixes it.

Checks 1, 4 and 7 are the ones this release is about.
