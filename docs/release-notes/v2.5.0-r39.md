# v2.5.0-r39 — Color FX buttons restyled

Skin-only update. The Mixxx build is the same as r38.

- **Color FX buttons match the rest of the screen.** SPACE, DUB ECHO, NOISE
  and FILTER now look like the rest of the Beat FX column: no filled
  background, a thin grey outline and grey lettering. The selected button
  gets a blue outline and blue lettering, the same blue as an active Beat
  FX. They are also bigger and easier to hit: taller rows and larger text.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

1. On the Overview tab, the four Color FX buttons sit under the Beat FX,
   in two rows, with every label fully visible.
2. **Tap each one**: the one you tapped turns blue and the others go grey.
   A FILTER knob then does that effect.
