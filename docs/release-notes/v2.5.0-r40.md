# v2.5.0-r40 — a safe headphone cue, and search that stays on the Search page

<!-- debs: rebuild -->

New Mixxx build. No skin files changed, but install the update as usual.

- **Pressing CUE can no longer blast your ears.** The headphone level was
  raised in r19 so a quiet cue could get loud enough, but that extra gain
  hit everything in the headphones. A loud track, both decks cued at once,
  or the HEADPHONES MIX knob turned towards MASTER could all come through
  far too loud and distorted. Now the extra boost applies only to the
  cued decks, never to the master, and a limiter stops the headphones from
  going past full volume. Quiet tracks still get the full boost.

- **A search only filters the Search page.** Searching for a track used to
  filter Browse as well, so you could not see the rest of the folder. Now
  Browse always shows every track. When you go back to Search your query is
  still there, and it searches whatever folder is selected at that point.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

## Field checks

1. Turn HEADPHONES LEVEL to about 3/4, cue a loud track and **press CUE**:
   it is loud but clean, with no crackle.
2. **Cue both decks at once**: no sudden jump in volume.
3. **Turn HEADPHONES MIX towards MASTER** with the level at 3/4: the master
   comes in at a sensible level, not a blast.
4. Cue a quiet track with the level at max: it is still loud enough.
5. On **Search**, type a query, then tap **Browse**: the whole folder is
   listed.
6. Tap **Search** again: the query is still in the box and the list is
   filtered again.
7. From Search, **LOAD** a track (you go back to Overview), then open
   **Browse**: the whole folder is listed.
