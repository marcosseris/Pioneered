# v2.5.0-r42 — Room LEDs with LedFx, and a LEDS button in Settings

<!-- debs: rebuild -->

New Mixxx build and new skin files. Install the update as usual.

- **LEDS button in Settings.** A new **LEDS** button sits beside WI-FI in
  the cog menu. It shows the room lights at a glance:
  - **Green** while the LedFx service is running and the Pi is on a
    network.
  - **Red** when LedFx is off or the Pi is offline.
  - Tap it to stop LedFx when it is green, or to start it when it is red.

  The light is only checked while the settings panel is open, so it costs
  nothing while you play.

- **Room LEDs (optional).** [LedFx](https://github.com/LedFx/LedFx) can now
  run on the Pi and drive WLED strips around the room from the music.
  Mixxx sends audio to LedFx through its **Booth** output. You set LedFx up
  from a laptop on the same network. LedFx runs at low priority on one core,
  so it cannot take CPU from the decks. Without LedFx installed, the LEDS
  button just stays red.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

To set up the room LEDs (once, optional):

```
sudo ./pi/ledfx-install.sh
```

Then, in Mixxx → *Preferences → Sound Hardware → Output*, set **Booth** to
`Loopback: PCM (hw:10,0)`. On a laptop, open
`http://<pi-hostname>.local:8888`. Set the audio device to the Loopback
capture device (`hw:10,1`), then add your WLED devices. The full steps are
in the README and `docs/pi-deploy.md`.

## Field checks

1. Open the cog: **WI-FI** and **LEDS** share one row, and the panel is
   still the same height.
2. Without LedFx installed: LEDS is red, and tapping it does nothing.
3. With LedFx installed and running on Wi-Fi: LEDS turns green within a few
   seconds of opening the cog.
4. Tap LEDS while it is green: it goes red and the strips stop. Tap it
   again: it goes green and the strips light up again.
5. Switch Wi-Fi off: LEDS goes red.
6. With Booth assigned, play a mix for a while: there are no clicks or
   dropouts on the master.
