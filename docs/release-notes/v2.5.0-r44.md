# v2.5.0-r44 — Screen sleep, LEDs off at boot, quieter RMX

<!-- debs: rebuild -->

New Mixxx build, plus changes to the Pi setup. Install the update as usual,
then reboot.

- **The screen switches off after 5 minutes of inactivity.** If nobody
  touches the screen or the DDJ-400 for 5 minutes and no deck is playing,
  the display turns off. Touching the screen or any control on the DDJ-400
  turns it back on.
  - A playing deck counts as activity, so the screen never goes dark
    during a set.
  - The touch that wakes the screen does nothing else, so you can't press
    a button by accident when you tap a dark screen.
  - To change the time, set `ScreenSleepMinutes` under `[Pioneered]` in
    `~/.mixxx/mixxx.cfg`. Set it to `0` to switch screen sleep off.
  - The updater turns on the Pi's display power management, so the screen
    really powers down instead of just going black. This needs the
    reboot after the update.

- **The room LEDs stay off until you turn them on.** LedFx no longer starts
  when the Pi boots. The lights stay off and don't react to the music until
  you tap **LEDS** in the settings menu. Tap it again to turn them off.
  The updater makes this change on your Pi. It also stops LedFx from
  waiting for a network connection when it starts, so tapping LEDS with no
  Wi-Fi is not held up.

- **RMX drums start at 30% volume** instead of 80%, which was too loud.
  LEVEL + and − work as before.

## About the freeze with no Wi-Fi

We tested booting with no Wi-Fi three ways: with the Wi-Fi radio off, with
the radio on but no known network in range, and with the room-LED audio
setup (Booth output into LedFx) switched on. **The freeze did not happen in
any of these tests.** Mixxx started and stayed responsive each time, and
LedFx just logged that it could not reach the lights.

With this update, LedFx no longer starts at boot, and it no longer waits
for the network when it does start, so it can't be the cause any more. If
the decks still freeze without Wi-Fi after you install this update, note
what freezes: the screen, touch, the DDJ-400's controls, or the sound.
Keep `~/.mixxx/mixxx.log.1` from the next start. It is the log of the
session that froze, and it will show where to look next.

## Install (on the Pi)

```
sudo update-pioneered.sh
```

or Cog → **SOFTWARE UPDATE** → UPDATE, twice.

Run the update **twice**. The first run installs the new updater, and the
second run uses it to apply the LedFx and screen settings. Then reboot.

## Field checks

1. After the reboot, the LEDs stay off. Open the cog: LEDS is red. Tap it
   and the lights start reacting (LEDS turns green on Wi-Fi).
2. Leave the unit untouched with no deck playing: after 5 minutes the
   screen switches off. Touching the screen turns it on, and the button
   you touched is not pressed. Moving a jog wheel or a knob also turns it
   on.
3. Play a track and leave it for more than 5 minutes: the screen stays on.
4. Open RMX: LEVEL shows 30.
